# 07_perturbation_icc

ICC(2,1) of 3D radiomics features after ±1-voxel morphological mask perturbation (same image, same extractor).

| File | Content |
|---|---|
| `feature_icc.csv` | Per-feature ICC(2,1) |
| `summary.json` | Summary proportions |
| `icc_on_primary517.csv` | ICC on the primary 517-feature subset (419/517 matched) |

**Result:** **45.3%** of 1595 features have ICC>0.75; median ICC **0.713** (n=629 discs).
